## 🎮 Interactive Robotics Simulation Hub (`robotics-sim.html`)

Our portfolio features a dedicated **Interactive Robotics Simulation Hub** showcasing 7 core algorithms from my published research papers & thesis:

1. **PID Control of DDMR + APF** (*ICCAS 2025*): Dynamic leader-follower formation control with artificial potential field obstacle avoidance.
2. **Kinematic Mathematical Model to 2D Plot**: Live integration of differential drive matrix equations: $\dot{x} = v \cos\theta, \; \dot{y} = v \sin\theta, \; \dot{\theta} = \omega$.
3. **Path Tracking vs Trajectory Tracking**: Interactive spatial vs time-synchronized trajectory tracking comparison.
4. **Vision-Based Leader-Follower**: Camera FOV & OpenCV bounding box object tracking simulator.
5. **Drone Swarm Flight Simulation** (*SICE FES 2025*): Swarm quadcopters flocking dynamics with sinusoidal altitude modulation.
6. **Autonomous Indoor Exploration** (*ICCAS 2024*): Comparative maze mapping using Floodfill Algorithm vs. Frontier-Based Method.
7. **LiDAR SLAM Autonomous Navigation** (*IJRA 2024*): 360° LiDAR laser scanning and occupancy point cloud mapping for Hexapod Search & Rescue robots.
