Laboratorium Simulasi Robotika Interaktif

Jelajahi algoritma kendali robotika otonom, sistem multi-agent, vision follower, drone swarm, dan navigasi LiDAR SLAM secara real-time

Modul 1: Fuzzy PID DDMR & Multi-Agent Formation Control (ICCAS 2025)

Simulasi kendali robot roda diferensial (DDMR) menggunakan pengontrol PID berparameter Fuzzy logic dengan penghindaran rintangan dinamis Artificial Potential Field (APF). Klik pada kanvas untuk menentukan lokasi target baru!

Modul 2: Model Matematika Kinematika ke Simulasi 2D

Mengubah persamaan diferensial linier dan angular roda ke dalam trajektori spasial 2D secara real-time.

Modul 3: Perbandingan Path Tracking vs Trajectory Tracking

Path Tracking (Pure Pursuit)

Robot mengikuti kontur geometri lintasan $(x,y)$ tanpa terikat kendala waktu $t$. Kecepatan linier $v$ menyesuaikan tingkat kelengkungan tikungan untuk meminimalkan *cross-track error*.

Trajectory Tracking (Time-Sync)

Robot **terikat kendala waktu $t$** untuk berada pada titik $(x(t), y(t))$ pada detik ke-$t$. Robot akan memutus sudut atau mempercepat daya motor jika tertinggal dari profil trajektori acuan.

Modul 4: Robot Following Kamera Vision (OpenCV Bounding Box)

Simulasi sensor visual kamera onboard robot pengikut. Kamera mengkalkulasi selisih lebar piksel Bounding Box target untuk mengendalikan jarak robot pengikut secara otomatis.

Modul 5: Drone Swarm Sinusoidal Altitude Flocking (SICE FES 2025)

Visualisasi kawanan quadcopter terbang dalam formasi 3D terkoordinasi dengan modulasi ketinggian sinusoidal.

Modul 6: Strategi Eksplorasi Indoor (Floodfill vs Frontier) (ICCAS 2024)

Perbandingan algoritma eksplorasi labirin indoor: pencarian petakFloodfill berbasis grid vs pemetaan perbatasan Frontier-based method.

Modul 7: Navigasi Otonom & Pemetaan LiDAR SLAM (IJRA 2024)

Simulasi pemindaian sinar laser LiDAR 360° dan pemetaan lingkungan bertahap (Occupancy Grid Mapping) untuk robot SAR berkaki enam.
